Privacy Data Coin (PDC) is a confidential mainnet. A wallet transfer hides the sender, the receiver, the amount, and the asset type. Staking, aliases, and confidential assets use that same path.

This manual explains how the network behaves. Protocol figures come from the PDC source. The edition number is release <a data-doc-release href="https://github.com/PrivacyDataCoin-Project/pdc/releases/latest"><span data-doc-version>v2.1.0</span></a> of [PrivacyDataCoin-Project/pdc](https://github.com/PrivacyDataCoin-Project/pdc), published <span data-doc-date>28 September 2026</span>. When that project publishes a new release, this number follows it.

Release v2.0.0 reset the network. Its genesis and peer-to-peer identity do not match v1.0.0.7. Install the current release on every wallet and node you run.

Start with [What PDC is](learn/what-is-pdc.md) if you are new, or [Getting started](use/getting-started.md) if you already want a wallet.
