Protocol

Mechanisms written into the PDC core.

The names below are the names in the code. The text says what each one hides or enables on this network.

01

Stealth addresses

An output pays a one-time address. The published wallet address does not appear on the chain as the receiver of the transfer.

02

d/v-CLSAG ring signatures

An input is signed together with decoys from the chain using d/v-CLSAG. The default set has 10 members. From hard fork 4 the mandatory set has 15.

03

Commitments and Bulletproofs+

The amount stays in a Pedersen commitment. Zero-knowledge proofs, Bulletproofs+ among them, show that the transaction is valid without printing the number.

04

Confidential assets

The asset id on a wallet transfer is blinded. An observer cannot tell PDC from a token issued on the same chain. The wallet whitelist points at api.privacydatacoin.com.

05

Zarcanum

Hard fork 4 in the source is named Zarcanum and activates after height 100. It is a hidden-amount proof of stake: odds follow the stake, and the balance stays in a commitment.

06

RandomARQ and PoS together

Proof of work is RandomARQ. The PoW target and the PoS target are 120 seconds each. Together they set a 60-second block target. A run of PoS blocks is capped at 21 in a row.
