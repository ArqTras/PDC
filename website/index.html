What the chain is for

Private payments, and the tools around them.

01

Confidential assets

Anyone can issue a token on PDC. Transfers blind the asset id, so a native coin and a user token look alike on the chain.

02

Aliases

A short name can stand in for an address. Registration fees are burned: the reward keys in the source are zero.

03

Auditable wallets

Default addresses start with Px. Auditable ones start with aPx, for the cases where a party must be able to prove a balance.

04

Escrow

The core carries an escrow service: propose, release, cancel, or burn. Marketplace offers live beside it.

05

Stake from the wallet

Proof of stake starts at height zero. A coinstake must age 10 blocks. Stake size stays inside a commitment under Zarcanum.

06

Integrated addresses

An address and a payment id can travel as one string beginning with iP. Auditable integrated addresses begin with aiPX.

Why default matters

A private option paints a target. A private default does not.

Privacy as a toggle

  • Most activity stays readable.
  • The few shielded transfers are easy to single out.
  • Choosing privacy becomes a signal of its own.

PDC wallet transfers

  • Sender, receiver, amount, and asset type are hidden together.
  • Every such transfer adds to the same anonymity set.
  • Using the wallet does not mark you as the exception.

Short answers

From the repository, not from a brochure.

Is there a public website already?

The project organization hosts a one-page placeholder at privacydatacoin.com. This site is the replacement, written against the arqtras/pdc sources.

Is the supply capped?

No. get_base_block_reward returns 1 PDC at every height. There is no premine. About 1,440 blocks fit in a day when the 60-second target holds, so emission is about 525,600 PDC a year.

Which software should I run?

Release v2.0.0, published 17 September 2026. It resets the network: new genesis and a new P2P id. It does not speak to v1.0.0.7.

Where is the code?

The chain, the daemon, simplewallet, and the Qt desktop GUI live at github.com/arqtras/pdc on the pdc branch.
