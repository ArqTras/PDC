Privacy Data Coin

Privacy Data Coin documentation

Privacy Data Coin (PDC) is a confidential mainnet. A wallet transfer hides the sender, the receiver, the amount, and the asset type. Staking, aliases, and confidential assets use that same path.

This manual explains how the network behaves. The numbers come from src/currency_core/currency_config.h on branch pdc, and from the v2.0.0 release published on 17 September 2026. When the sources change, this manual should change with them.

Release v2.0.0 resets the network. Its genesis and peer-to-peer identity do not match v1.0.0.7. Use v2.0.0 wallets and nodes together.

Start with What PDC is if you are new, or Getting started if you already want a wallet.
